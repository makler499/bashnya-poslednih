# Башня Последних — прототип 0.2

Браузерный игровой прототип, вдохновлённый механиками survival tower-defense. Дизайн и игровые материалы авторские; это не официальный продукт Warcraft III / Blizzard.

## Играть

Откройте опубликованный сайт GitHub Pages или локальный `index.html` в Microsoft Edge.

### Возможности прототипа

- Автоматические атаки центральной башни
- Волны врагов и усиление сложности
- Золото, покупки оружия и улучшения
- Сохранение результатов **только в локальном хранилище браузера**

### Что ещё не реализовано

- Настоящая регистрация игроков и облачные сохранения
- Полноценный 3D-движок, сетевые матчи, полный набор оружия и точный баланс оригинальной карты
- Нативное приложение Android

## Публикация через GitHub Pages

1. Создайте **публичный** репозиторий на GitHub (например, `bashnya-poslednih`).
2. Добавьте в корень репозитория файлы `index.html`, `.nojekyll`, `README.md` и запишите изменения в ветку `main`.
3. Откройте `Settings` → `Pages` → `Build and deployment` → `Deploy from a branch` → `main` / `(root)` → `Save`.
4. Дождитесь статуса `Your site is live at ...` на странице Pages. Ссылка появится только после успешной публикации.

Код и контент готовы к переносу на другой статический хостинг.
