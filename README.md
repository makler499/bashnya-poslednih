# Tower Survivors · Башня Последних

Браузерная адаптация Tower Survivors с боевой симуляцией и игровыми данными из v2.0. На [GitHub Pages](https://makler499.github.io/bashnya-poslednih/) доступны одиночная оборона и матч на восемь башен с ботами.

Управление

- **1–8** — покупка в лавке
- **R** — обновление товаров
- **C** — очистка арены
- **F** — скорость матча
- **F1–F8** — переключение между башнями
- **Пробел** — пауза

## Сборка

Исходники находятся в `source/`. Для локального запуска установите Node.js 24 и выполните из корня репозитория:

```sh
cd source
npm ci
npm test
npm run build
npx vite preview --host 127.0.0.1
```

Сборка в `source/dist/` содержит HTML, `assets/` и ресурсы из `map-art/`. GitHub Pages публикует `index.html`, `assets/` и `map-art/` из корня ветки `main`. Чтобы обновить сайт, скопируйте в корень файлы из `source/dist/` и отправьте изменения в `main`.

Сетевые комнаты и сетевые профили требуют отдельно запущенного игрового сервера. После сборки сервер можно запустить из `source/` командой `npm start`.

В правом верхнем углу находится таблица игроков из триггера `Multiboard`. Столбцы «Урон» и «Доход» показывают вложения в единицах по 500 золота. Очки берутся из сохранённых достижений на начало матча. Окно «Доход и урон» показывает доход своего игрока и оружие выбранной башни, как при просмотре через «Шпионаж» в оригинале. Средний урон оружия за экземпляр пересчитывается каждую игровую секунду, описания обновляются раз в пять секунд. Окно выводит фактически снятое здоровье по правилам браузерной симуляции. Оригинальные допуски для отдельных эффектов и местоположение нативного окна Warcraft III не проверены покадрово.

Автор оригинальной карты — [Nethalythic](https://www.hiveworkshop.com/threads/tower-survivors.353429/). Игровые правила сверены с [архивом v2.0 на WC3Map](https://wc3map.com/maps/tower-survivors/tower-survivors-v2-0-449501/). Классические модели и эффекты Warcraft III принадлежат Blizzard Entertainment.

Рельеф и проходимость взяты из `war3map.w3e` и `war3map.wpm`. В `war3map.doo` этой версии нет размещённых декораций. Карта использует набор Village Fall, а положения башен и правила появления врагов заданы в `scripts/war3map.j`. Список моделей, облики и параметры отображения находятся в `map-art/manifest.json`.

Шесть положений камеры используют углы и дистанции из `UI/MiscData.txt` Warcraft III. На узком экране камера отдаляется, чтобы башня помещалась в кадр. Момент вылета вражеского снаряда рассчитывается по точке атаки из данных юнита. Модель снаряда переходит к анимации попадания, а звук запускается по событию попадания симуляции. Звук начала боя и смены лавки следует за своей башней при просмотре соперника.

В браузере ещё отличаются интерполяция анимаций, поиск обходного пути после отбрасывания и порядок нативных рикошетов. Модели без отдельной анимации удара, например Сэмуайз `n00C`, используют короткую цветовую вспышку. Для вражеских слотов 16–19 используются запасные командные цвета. Браузерные ускорение, ручной ремонт и ранний запуск доступны через панель управления.

Для `H010`, `H01R` и `H025` отсутствуют отдельные вложенные эффекты появления `NagaBirth_Small`, `NagaBirth` и `DalaranBirth`. Основные модели этих обликов и их анимации доступны. Тайминги отдельных заклинаний, включая рассеивание «Паразита», выбор точки взрыва ракет и работу отдельных модификаторов лавки, требуют сверки в Warcraft III. Сетевые комнаты используют общую симуляцию на отдельном сервере.
